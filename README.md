# Moduli spaces of graphs

An interactive companion to a lecture on moduli spaces of metric graphs.

- Pick a type (g, n) with at most 250 stable graphs.
- **Poset:** all stable graphs of that type, ordered by edge contraction.
- **One graph:** half-edge data (H, V, r, ι, w, m), the genus computation, the stability budget behind the finiteness lemma, the automorphism group as permutations of half-edges (with animations), and the graphs directly above and below.
- **The space:** for (0,4), (1,1), (0,5), (1,2) and (2,0), a picture of the space with a draggable point and a live drawing of the metric graph at that point. For other types: cell counts by dimension and the Euler characteristic.
- **Lecture notes** (`lecture.html`): the lecture written out, from segments in ℝ^r and lines through the origin to half-edges, stability, the finiteness proof, contraction, the definition of the space, the examples (M_{0,4}, M_{0,5}, M_{1,1}, M_{1,2}, M_2), dual graphs of nodal curves, and exercises. Every figure is interactive.

Everything is computed in the browser (`js/core.js`): graphs are generated by splitting vertices, starting from the single vertex of weight g, and are identified up to isomorphism by a canonical form.

## Running locally

Open `index.html` in a browser. No build step.

## GitHub Pages

Push the repository and enable Pages (Settings → Pages → deploy from the main branch, root folder).

## Files

- `index.html`, `style.css`: the explorer
- `lecture.html`, `lecture.css`: the lecture notes
- `js/core.js`: stable graphs, contraction, automorphisms, enumeration
- `js/draw.js`: graph layouts and SVG drawing, including metric graphs
- `js/spaces.js`: the cell structures of the drawable spaces
- `js/spacepic.js`: drawing those spaces (shared by both pages)
- `js/app.js`: the explorer interface
- `js/lecture.js`: the figures in the lecture notes
